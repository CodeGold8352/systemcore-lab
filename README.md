# SystemCore Lab

Student lab for FRC Team 8352 CODE Gold: how to wire the 2027 SystemCore robot controller.

Open `index.html` in a browser, or view it on GitHub Pages. Progress is saved in your browser only.

**Preliminary:** based on SystemCore beta testing notes (November 2026). Check the official
[2027 WPILib docs](https://docs.wpilib.org/en/2027/) before wiring a real robot.

`lab.js` and `lab.css` are the shared lab engine, copied from the
[Auto Lab](https://github.com/CodeGold8352/auto-lab) repo.
