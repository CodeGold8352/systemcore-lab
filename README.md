# Wiring Lab

Student lab for FRC Team 8352 CODE Gold: how to wire an FRC robot.

1. The power path: battery to motor
2. CAN: how the controller talks to the motors
3. Good connections and checking your work
4. Wiring the 2027 controller: SystemCore (preliminary)

Open `index.html` in a browser, or view it on GitHub Pages. Progress is saved in your browser only.

Wire sizes and colors follow the usual FRC robot rules. Check the current game manual before
inspection. **The SystemCore lesson is preliminary:** it's based on beta testing notes (November 2026).
Check the official [2027 WPILib docs](https://docs.wpilib.org/en/2027/) before wiring a real robot.

`lab.js` and `lab.css` are the shared lab engine, copied from the
[Auto Lab](https://github.com/CodeGold8352/auto-lab) repo.
